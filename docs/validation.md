# Validation status

The package is a design skill and graph, not a renderer. Automated tests prove local graph/packaging invariants, not successful design quality, account access or live plugin compatibility.

## Automated

- Every nonempty subset of seven platforms (127) can reach handoff in dependency order using labeled synthetic evidence.
- Unknown platforms, duplicate IDs, cycles and missing references fail validation.
- Unfinished or blocked dependencies prevent downstream completion.
- Required evidence and current dependency receipt structure are enforced at record time.
- Retry limits, N/A restrictions, relocation, archive integrity and overwrite refusal are checked.
- Synthetic test URLs/jobs never represent actual Figma or Higgsfield execution.

## Live acceptance scenarios to run with connected accounts

1. Browser path: inspect a designated Figma file, create a small landing + web design, verify editable components, page order, real text and responsive behavior, and exercise primary/recovery prototype links.
2. Higgsfield: generate one authorized asset, persist/retrieve its job ID, place it in Figma and verify its real crop. Interrupt/resume without submitting another generation.
3. Dependency freshness: install an older Impeccable release in an isolated test profile; resolve the current official revision, update through its supported path, reread the skill and record the actual receipt. Verify blocked behavior when the host cannot verify a managed plugin.
4. Native: run a Windows and iOS design with platform-appropriate input/navigation. Confirm they are not merely resized copies of a browser screen.
5. Partial access: remove canvas write capability; verify planning can continue but the agent does not claim completed editable screens.
6. ChatGPT: upload the exported ZIP through the Skills UI, confirm its references are accessible and run the browser-only/manual-ledger path.

These live scenarios are not claimed as completed in v0.1. Installation of the ZIP into ChatGPT and freshness of host-managed integrations are subject to the user's account and workspace controls.
