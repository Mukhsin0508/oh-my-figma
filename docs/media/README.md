# README media kit

Original graphics generated through the Higgsfield MCP integration for oh-my-figma.

| Asset | Hook | Use |
|---|---|---|
| [hero.png](hero.png) | One brief. Every screen. | README opening and project announcements |
| [workflow.png](workflow.png) | From idea to handoff. | Explain Brief → Design system → Screens → Handoff |

Both assets are 2752 × 1536 PNG files, using ivory, ink and chartreuse. Keep the concept-illustration label visible. They depict the intended workflow rather than actual screenshots of a completed design run.

Prompts and generation job IDs are in [manifest.json](manifest.json). Requested model: `nano_banana_pro`; the provider reported completed outputs under `nano_banana_2`. The images were visually inspected for headline accuracy, clear sequence, cropping and legibility before inclusion.

These are flattened graphics, not editable Figma files. The media kit does not change the package's live end-to-end validation status.
